# Video demo

## 90-second recording script

This script makes the submission easy to record with Loom, QuickTime, or OBS.
Record the browser at `http://localhost:8000/app/` and keep the pointer visible.

| Time | Action | Narration |
|---:|---|---|
| 0:00 | Show the hero and scroll to the graph | “Potter Graph turns seven novels into a typed, evidence-backed network.” |
| 0:12 | Toggle spells and places; raise the encounter slider | “Every edge is repeated paragraph co-occurrence. Filters separate entity types and remove weak evidence.” |
| 0:28 | Search `Expecto Patronum`, select it | “Profiles expose totals, a seven-book timeline, spell effects, and strongest connections.” |
| 0:43 | Reset; click `Dobby`, then `Lord Voldemort` | “Selecting two entities computes their shortest narrative path directly in the browser.” |
| 0:57 | Scroll to Insights | “Insights are calculated from graph data. The strongest non-human bridge and spell timeline are not hard-coded.” |
| 1:12 | Scroll to Method | “The pipeline is deterministic: segment, recognise aliases, connect shared evidence windows, then explore.” |
| 1:25 | End on repository README | “The README covers reproduction, precision and recall, limitations, architecture, and responsible data use.” |

### Recording checklist

- Use a 1440×900 browser window at 100% zoom.
- Pause briefly after each interaction so labels remain readable.
- Export as `docs/demo.mp4` or paste an unlisted Loom/YouTube link above.
- Keep the final recording under two minutes.
